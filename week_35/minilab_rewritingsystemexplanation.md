# Guided Project Overview

## Problem Statement

Students often lack guided support when learning course material and are left choosing between struggling alone or using tools that simply provide answers.

---

## Target User

Technical students need on-demand help that supports learning concepts rather than giving away solutions.

---

## System Explanation

Guided uses AI-powered curriculum retrieval to connect student questions with relevant course content and learning resources.

---

## Value Statement

Guided provides students with 24/7 course-specific support, helping them learn independently outside class hours.
